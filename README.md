# Simplifi Tampermonkey Script

A Tampermonkey / Greasemonkey userscript for [Quicken Simplifi](https://simplifi.quicken.com/).

## Features

- **Account Overview Sorting**: Automatically sorts accounts in the overview list by balance and name.
- **Account Count Header**: Shows total count of accounts in the account settings page header.
- **Investment Portfolio Visualizer**: Renders an interactive Google Charts pie chart breakdown of your investment holdings directly inside Quicken Simplifi's investing page.

## Installation

1. Install a userscript manager browser extension such as [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Click [**Install Script**](https://raw.githubusercontent.com/tjipz8/simplifi/main/simplifi.user.js) to install directly into Tampermonkey.
